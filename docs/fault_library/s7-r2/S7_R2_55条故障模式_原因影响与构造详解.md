审查日期：2026-10-21。根据本版工作簿、原HTML分类定义、本地555案Issue/PR/patch归档及当前注入源码核对；原R2文件保留，本文为修订副本。

**55项全部保留：33项有效规划（30推理、3训练），22项待补证/缺口；22个PH配方；当前完整配方验收0。** 有代表小类27/31、6/6大类；这只表示有受支持子情形，不表示整类故障均已覆盖。

“有效规划”指存在可解释的候选规则及来源，仍需目标入口、参数/布局、校准、消费者观察与恢复验收。M为机制变异，P为有来源的现象/状态代理；P可以改变选定输出或内部状态，但不能用任意扰动冒称原机制已复现。PH编号用于复用去重，不等同于独立根因。

A5/950作为展示与支持目标优先保留，实际首次实施优先A2/A3。设备列表示原案例来源，不是本轮硬件实测；A5备选不能自动计入A2/A3覆盖。全部已有根因归芯片使能／CANN；软件错误使用UB、同步或通信资源，不因此变为硬件本体故障。

分类沿用HTML的6大类、31小类、55条件及64父子关系。每例选最强相关主展示，原副挂接保留；本代表不支持的父关系不计有效覆盖。quant_scale只支持原HTML登记的动态系数零分母子项；minus_one按HTML宽定义支持动态哨兵，不表示负物理下标。

通用验收：健康基线 → 接入未启用 → no-op → 单一变异 → 独立核对选区/未选区及真实消费者 → 撤销后同请求恢复。分开记录未命中、命中无变化、异常形成、检测器识别；持久cache/inplace必须恢复快照或重建。

## 01. optional输入省略 / null — `optional_absent`

**设备来源：A2/A3｜参考业务场景：训练｜状态：候选待证。**

**模式：FAG的dQ头维步长用错。** 案例：`ops-transformer-2272-FlashAttentionScoreGrad`；主责/配方：`待定（P-04） / PH-0419-01`。

**故障原因：**FlashAttentionScoreGrad #2272的cube_op_bn2在写dQ时误用N2作为头数/步长，正确应使用N1；dK方向另有相反混用。两条梯度路径需要分别检查。

**正常结果与异常：**正确：该算子按合法输入和属性返回与参考语义一致的结果；具体golden tensor及容差未知。；错误：短序列FAG GQA NoMask BSH/SBH精度比对失败

**故障影响：**短序列GQA、NoMask、BSH/SBH场景精度比对失败；资料没有给出dQ完整错误位置、幅度及golden。

**合法触发与构造方法：**待定P-04：能取得实际head布局时，重放错误offset/stride并在安全缓冲里生成dQ；当前表只给了选区y+δ的粗代理方向，δ与区域必须校准，不能假定是全零或NaN。

**证据与使用边界：**NoMask与失败同场景，但尚未闭合“省略mask”是否激活该路径。训练候选，不计本条件有效覆盖。

**分类：**主展示 退化输入；原目录 退化输入／省略输入。

**逐项复核：**N1/N2 地址公式明确，可设计安全布局模型；原 dQ 区域与该路径准入仍缺，保留待证合理。 NoMask 是 Issue 明示合取条件；训练 FAG 不能直接登记推理前向覆盖。

**证据与使用边界：**缺零值/非零值对照及512路径原输出，不能把“参数为0”直接解释成根因；不计有效覆盖。

## 09. 空与非空对照 — `positive_extent`

**设备来源：A2｜参考业务场景：推理｜状态：候选待证。**

**模式：相同非空BF16张量被Equal判为False。** 案例：`ops-math-1143-TensorEqual`；主责/配方：`P-03 / PH-0028-01`。

**故障原因：**TensorEqual #1143的BF16底层比较路径存在问题；修复将promoteType升到FP32后比较，具体kernel内部原因仍未完整给出。

**正常结果与异常：**正确：两个相同有限BF16 tensor比较应为True；错误：A2 arm64两个相同BF16[5,5,5,5,5]反复200次equal时得到错误False；出现频率未记录

**故障影响：**A2 arm64两个相同BF16 tensor应比较为True；原记录反复200次时出现False，没有记录发生频率。

**合法触发与构造方法：**P-03候选：选择真实Equal健康应True的布尔标量，定次改为False；另建一组合法空张量对照，两个对象彼此同shape/dtype，但与非空组shape不同。

**证据与使用边界：**非空失败已知，空/非空差异对照未闭合；新建空输入测试不会自动增加历史证据。

## 54. 特殊函数参数 — `scalar_branch`

**设备来源：A2/A3｜参考业务场景：训练｜状态：候选待证。**

**模式：Swish梯度漏乘swishScale。** 案例：`ops-nn-2879-GroupNormSwishGrad`；主责/配方：`P-05 / PH-0223-01`。

**故障原因：**GroupNormSwishGrad #2879的多个分块路径遗漏swishScale乘法。资料中的内部中间式为s*t−s*t/(exp(−s*t)+1)+1，旧式漏掉分子项的s。

**正常结果与异常：**正确：正确公式：；；$$；dSwishTemp_i = swishScale \cdot dYTemp_i - \frac{swishScale \cdot dYTemp_i}{\exp(-swishScale \cdot dYTemp_i) + 1} + 1；$$；错误：GroupNormSwishGrad计算公式不对，漏乘了swishScale

**故障影响：**s不为1时可能产生梯度偏差；s=1会掩盖这部分差异，未提供该条件的专用分支/邻域对照。

**合法触发与构造方法：**P-05候选：取得真实dYTemp=t和swishScale=s，按旧t−t/(exp(−s*t)+1)+1替换该内部中间量，再由后续groupnorm梯度消费。

**证据与使用边界：**这是训练内部公式，不把该式当完整Swish导数；窄定义的特殊函数分支代表性待证，不计本条件覆盖。

**分类：**主展示 控制；原目录 控制／阈值边界。

**逐项复核：**内部dSwishTemp旧公式可单独变异，但特殊阈值分支的历史代表未闭合，当前有效0合理。 控制／阈值边界目录保留，已正确说明s≠1只使通用公式差异显露，并非证明专用分支。
