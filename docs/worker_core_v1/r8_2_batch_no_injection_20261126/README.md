## 对黄区判断的修正

黄区最新文字称scope0三轮组成相同而OFF top5不同，同时据此说“不是残留、支持批次切分”。后半句不能由前半句推出。scope1表还记录OFF额外B1，不能同时称三轮完全相同。需要按真实请求/位置轨迹复核，不能仅凭 batch size 总览断因。

本对照证明：①差异可在从未注入时出现；②相同实际组成是可比条件，但不是确定性的充分条件；③本次连续后两轮稳定，不代表所有冷启动、模型或A3都稳定。它不证明黄区那个OFF差异一定同源，也不证明公共故障恢复失败或成功。

当前处置：保留原件和本次失败基线，不挑选输出、不因结果重跑、不新增噪声容差或协议放宽。已有“连续两次无注入、全有限且完全一致”的预热要求仍然适用；正式三轮必须在基线门禁通过后开始，同组成的OFF仍必须精确。先前组成不匹配重发的蓝区结果保留为那一次运行证据，不能外推成全部Batch问题已修复。若稳定预热后仍在同组成下不精确，保持失败并取同一次运行证据，不能解释为成功。
