## 产品能力与效果口径

r7.4.1产品路径已支持服务保持运行时attach/enable/status/disable/detach，只覆盖开启期间且满足声明范围的请求。并非任意生产部署、任意输入或未登记组合都可执行。

`product_effect_probe.py`使用temperature=0、seed=42、生成4token，completions请求logprobs=5；chat接口的参数按实际API设置logprobs=true及top_logprobs=5。返回的是top-k **log概率**，不是原始logits，不能由它重建原始logits的绝对值。已有工具分别记录tokens/text/top5变化与真实观察的full_logits_changed；完整logits缺证据时为null。服务如未启用logprobs能力，应明确拒绝/报告缺失，不补造数值。

不要求每个故障都改变top-k或token：微小扰动可能未进入top-k；非有限值单列；Batch需要同一decode批至少两个真实请求。真实消费、覆盖和恢复仍用各能力证据判断。若产品要求用户直接读取原始top-k logits，当前logprobs接口不满足该字面要求，需另列只读观测接口需求，不在本次偷偷扩大改动。
