# Independent source66 public Core8/18 original review

The reader `experiments/c2c3_closure_20261117/review_tensor_worker_core_source66.py`
uses only the Python standard library. It reads immutable files and prints one
compact JSON report; exit 0 means the recorded, source-bound public C2/C3
receipts reconcile. Exit 2 preserves missing, contradictory, or refused
evidence. It imports no Torch, injector, vLLM, or DSO and writes no evidence.

It reuses the frozen independent coverage auditor and the existing MoE
producer/native-consumer JSON checks. The new layer verifies all 39 original
Host/Runtime RPCs and their standalone files, ten distinct actual requests,
four complete healthy controls, all naturally observed targets, each target's
one C2 and two C3 occurrences, actual model effects and exact OFF, the original
live C2 object issuance/use receipt, and final unregister/detach/removal.
RMS targets are joined to actual Native weight-owner module identities, including
the fused tuple return and unchanged auxiliary outputs. MoE joins the actual
top-k/routing/expert/combine objects, paired replacement I/P, unchanged H,
original native call, and complete group/readback/oracle receipts. No result
status or hit total substitutes for these records.

Input-token and position digests are recomputed with actual dtype/shape and
the frozen `tensor_modules._identity` raw-byte encoding. Model hidden/logits
and effect tensor payloads were not saved as independent bins; their complete
hash/readback receipts remain source-bound. External model weights and method
files are bound by recorded hashes but not reread by this CLI. Cleanup is also
source-bound; no saved independent process-stack measurement is invented.
