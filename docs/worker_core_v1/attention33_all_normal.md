# 33: all discovered decode targets, normal only

This increment establishes a **new normal-only scope**. It grants no F, C1,
C2, C3, live C2Proof, E5 or generic device qualification. The accepted source105
first-layer C1 and its original results are unchanged. Its normal certificate
cannot qualify this package or the other 27 targets.

The fresh variant is `tnd_page16_arch22_all_normal`; its vendor is
`dcat_f33_arch22_all_normal_transformer`. The dedicated host header accepts only
`arch22_all_normal` and baseline/OFF phases. It preserves native S2=512 and the
original loop, SplitCore, workspace, serializer and kernel arithmetic. There
is no 256 selection branch. Every captured host call must match the original
observer's active token, owner, generation, PID/OS TID, discovered target-set
hash, actual module object ID and ordinal. Python thread identity is recorded
separately. The host cannot independently interpret a Python object ID; the
source-bound adapter proves its relationship to the current call.

`AllNormalWorkerSession` reuses `AttentionExecutionAdapter` and its actual
prefill/decode scheduler, actual parent/module discovery, original-once API
closures, wrapper ownership and retryable cleanup. The trusted Worker probe
selects this session with `--arch22-all-normal-bridge`; no caller supplies layer
names or tensor arguments. It is a standard Worker experiment over trusted
setup/expect/finish RPC helpers, **not a new public Core fault Provider**.
Registry, Host, Runtime and exporter are unchanged.

Each request records all 28 prefill plus all 28 decode calls. The 28 decode
targets are discovered from the loaded model's reviewed Attention/impl objects;
missing, repeated, replaced or ambiguous objects refuse the experiment. Every
decode call gets a separate live Q/mask/page-table/current writer/cache binding,
read-before complete logical K/V hashes, full Q bytes and immediate output bytes.
The same inputs and output objects are checked again after the real consumer.
All 87 complete model payloads are retained and rehashed. Both arms use this
same capture implementation. The private arm has 28 normal host/launch receipts
in each of its first four phases (112 total); its fifth phase is an observer-only
healthy call through the unchanged loaded package. Each arm therefore has 140
scoped decode observations and 280 actual Attention calls over five requests.
Warmup and the final ordinary post-clean request are outside that denominator.

The independent reader verifies raw files, actual request/root row mapping,
all discovered object IDs, each Native token and current registration, ELF
contents/symbols, final private POD and complete SplitCore arrays. It never
interprets stock arguments using the private ABI. Same-phase stock/private pairs
require exact raw input signatures and 435 complete payload pairs. Within-arm
normal repeats may have independently proven page relocation; raw differences
remain reported. All 28 per-target comparisons must pass. One missing target
or runtime scope retains a refusal; 27 good targets are not a complete normal
bridge. Cleanup errors, foreign wrappers and uncertain drain retain the owner
and original error until retry. There is no fault retry or fault mode here.

Mask bytes and read-before logical K/V are hash-only; matching complete later
K/V bins are rehashed. This does not prove absence of intervening writes.
Selected ACLNN callsite ownership remains unobserved. The final ordinary
post-clean request proves tokens/text only, not post-unregister logits.
