# Typed FIA: retain unclassified prepared executors

An early selected-GWS binding failure can occur before the group records its
executor. The independent typed trace still owns the actual GWS registration.
The group therefore requires that trace's complete quiescent state before both
drain and restore: no preparing, prepared or executing registrations, no errors
or dropped rows, and complete before/after counts. A null group executor is not
evidence that no executor exists.

If before-execute sees the same selected native call with an unbound executor,
it refuses execution. A substituted output must not execute before the Engine
has established backups and the exact lease. A distinct unselected call still
executes its original once and records the existing scope failure.

The actual-runtime host SDK contract now has 16 cases. The new case generates a
real fixture GWS registration, rejects its group binding before recording the
executor, then verifies that selected execute, drain, restore and removal all
refuse while the owned descriptor and lease remain retained. The Python builder
requires that new case count. ABI layout sizes and the numerical mechanism are
unchanged; source/build fingerprints change and require a fresh group DSO.

The already successful source57 parent/group-a2 CPU artifacts remain immutable.
They do not contain this additional gate and must not be used for the typed
device case. Existing parent verification also hashes the entire group source,
so the next source requires a fresh parent metadata contract, even though the
trace/proxy source and actual metadata capture bodies did not change. No device
or Native numerical qualification follows from these CPU contracts.
